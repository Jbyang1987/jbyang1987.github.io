线性映射 / 相似上三角化与若当标准形

利用若当标准形, 可完全解决常系数线性微分方程组的求解问题.
例题
设\(x,y,z\)都是\(t\)的函数，求解常微分方程组
\[ \begin{cases} \frac{\mathrm{d}x}{\mathrm{d}t} = 3x - 2y + \ z\\ \frac{\mathrm{d}y}{\mathrm{d}t} = 2x - 2y + 2z\\ \frac{\mathrm{d}z}{\mathrm{d}t} = 3x - 6y + 5z\\ \end{cases} \]
改写原方程组为 \(\frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t} = A\mathbf{x}\). 作线性代换 \(\mathbf{x} = T\mathbf{x}^*\), 则
\[\frac{\mathrm{d}\mathbf{x}^*}{\mathrm{d}t} = T^{-1}AT\mathbf{x}^*. \quad \text{ 即, } \quad \begin{cases} \frac{\mathrm{d}x^*}{\mathrm{d}t} = 2x^* + y^* \\ \frac{\mathrm{d}y^*}{\mathrm{d}t} = 2y^* \\ \frac{\mathrm{d}z^*}{\mathrm{d}t} = 2z^* \end{cases} \]
解此方程组得 \(z^* = c_1e^{2t},\ y^* = c_2e^{2t},\ x^* = (c_2t + c_3)e^{2t}.\) 再利用 \(\mathbf{x} = T\mathbf{x}^*\), 即得到通解是
\[ \begin{cases} x(t) = (c_2t + c_2 + c_3 - c_1)e^{2t} \\ y(t) = (2c_2t + 2c_3)e^{2t} \qquad \text{其中 $c_1, c_2, c_3$ 为任意常数.}\\ z(t) = (3c_2t + 3c_3 + c_1)e^{2t} \end{cases} \]
