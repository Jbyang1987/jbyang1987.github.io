§7.1.1

线性映射 · 第1页

线性映射 / 线性映射

给定一个数组向量空间之间的映射\({\mathscr A}\colon {\mathbb F}^n\rightarrow {\mathbb F}^m\). 若\({\mathscr A}\)满足
\[\tag{$*$} \begin{split} {\textcolor[rgb]{0,0,1}{\text{(保持加法)\quad }}} &{\mathscr A}(\vec{a} + \vec{b}) = {\mathscr A}(\vec{a}) + {\mathscr A}(\vec{b});\\ {\textcolor[rgb]{0,0,1}{\text{(保持数乘)\quad }}} &{\mathscr A}(\lambda\vec{a}) = \lambda{\mathscr A}(\vec{a}) \end{split} \]
则\({\mathscr A}\)称为从\({\mathbb F}^n\)到\({\mathbb F}^m\)的一个线性映射.
我们有如下一一对应:
从\({\mathbb F}^n\)到\({\mathbb F}^m\)的全体线性映射 \(\underset{{\mathscr A}(\vec{x})=A\vec{x}}{\overset{\quad 1:1\quad }{\leftrightarrow}}\) \({\mathbb F}^{m\times n}\)
例题 （伸缩变换）
\(\begin{pmatrix} x\\y\\\end{pmatrix}\mapsto \begin{pmatrix} k_1x\\k_2y\\\end{pmatrix} = \begin{pmatrix} k_1&\\&k_2\\\end{pmatrix}\begin{pmatrix} x\\y\\\end{pmatrix}\).
例题 （旋转变换）
\(\begin{pmatrix} x\\y\\\end{pmatrix}\mapsto \begin{pmatrix} x\cos\theta-y\sin\theta\\x\sin\theta+y\cos\theta\\\end{pmatrix} = \begin{pmatrix} \cos\theta&-\sin\theta\\\sin\theta&\cos\theta\\\end{pmatrix}\begin{pmatrix} x\\y\\\end{pmatrix}\).
例题
  • \(\bullet\) \(\begin{pmatrix}1&\\&1\end{pmatrix}\) \(\leftrightarrow\) 恒等变换; \(\bullet\) \(\begin{pmatrix}0&\\&0\end{pmatrix}\) \(\leftrightarrow\) 零变换;
  • \(\bullet\) \(\begin{pmatrix}\lambda&\\&\mu\end{pmatrix}\) \(\leftrightarrow\) 伸缩变换; \(\bullet\) \(\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}\) \(\leftrightarrow\) 旋转变换;
  • \(\bullet\) \(\begin{pmatrix}1&0\\0&-1\end{pmatrix}\) \(\leftrightarrow\) 反射变换; \(\bullet\) \(\begin{pmatrix}1&\\&0\end{pmatrix}\) \(\leftrightarrow\) 投射变换;

§7.1.2

线性映射 · 第2页

线性映射 / 线性映射

接下来将线性映射推广到一般的线性空间上.
定义 （线性映射,线性变换和同构）
设\(V\)和\(W\)为两个\({\mathbb F}\)-线性空间.(注意:这里\(V\)和\(W\)不再要求是数组向量空间,而只是一般的线性空间.)
  1. 若映射\({\mathscr A}\colon V\rightarrow W\)满足
    • \({\mathscr A}(P_1 + P_2) = {\mathscr A}( P_1) + {\mathscr A}(P_2)\);
    • \({\mathscr A}(\lambda P_1) = \lambda{\mathscr A}( P_1)\).
    则称\({\mathscr A}\)为从\(V\)到\(W\)的线性映射.
  2. 若\(V=W\),则称线性映射\({\mathscr A}\)为\(V\)上的一个线性变换.
  3. 若线性映射\({\mathscr A}\)为双射,则称\({\mathscr A}\)为线性空间\(V\)到\(W\)的一个同构映射. 若两个线性空间之间存在同构映射,则称它们互相同构.
性质 （同构基本性质）
  • 同构映射的逆映射也是同构映射.
  • 同构为等价关系.
  • (同一域上的)有限维线性空间同构当且仅当它们维数相同.
例题
  1. 单位变换(恒等变换): \(\varepsilon\colon V\rightarrow V\), \(x\mapsto x\);
  2. 零映射: \(\varepsilon\colon V\rightarrow W\), \(x\mapsto 0\);
  3. 微分变换:
    \[{\mathscr A}\colon {\mathbb F}_n[x] \rightarrow {\mathbb F}_n[x],\quad p(x)\mapsto \frac{\mathrm{d}}{\mathrm{d}x}p(x).\]
  4. 积分变换:
    \[{\mathscr A}\colon C[a,b]\rightarrow C[a,b],\quad f\mapsto \int_{a}^{b}K(x,t)f(t)\mathrm{d}t\]
    其中 \(K(x,t)\)为\([a,b]\times[a,b]\)上的实值连续函数.
  5. 线性化变换: 记\(V\)为\([a,b]\)上的函数集合.
    \[{\mathscr A}:V\rightarrow V,\quad f\mapsto (1-x)f(a)+xf(b).\]
  6. 矩阵对应的线性映射: \(A\in {\mathbb F}^{m\times n}\).
    \[{\mathscr A}\colon {\mathbb F}^n\rightarrow {\mathbb F}^m,\quad x\mapsto Ax \text{(列向量)}.\]
例题
  1. 投影映射: \({\mathscr A}\colon {\mathbb F}^n\rightarrow {\mathbb F}^r\), \((x_1,\cdots,x_n)\mapsto (x_1,\cdots,x_r)\);
  2. 嵌入映射: \({\mathscr A}\colon {\mathbb F}^r\rightarrow {\mathbb F}^n\), \((x_1,\cdots,x_r)\mapsto (x_1,\cdots,x_r,0,\cdots,0)\);
  3. \({\mathscr A}\colon {\mathbb F}^n\rightarrow {\mathbb F}^n\), \((x_1,x_2,\cdots,x_n)\mapsto (x_n,x_{n-1},\cdots,x_1)\);
  4. 设\(A\in {\mathbb F}^{p\times m}\)以及\(B\in {\mathbb F}^{n\times q}\)为固定矩阵,
    \[{\mathscr A}\colon {\mathbb F}^{m\times n}\rightarrow {\mathbb F}^{p\times q},\quad X\mapsto AXB.\]
  5. 设\(V\)为\({\mathbb F}\)上的线性空间, \(\alpha_1,\cdots,\alpha_n\)为 \(V\)中的任意 \(n\)个向量.
    \[{\mathscr A}\colon {\mathbb F}^n \rightarrow V,\quad (x_1,\cdots,x_n) \mapsto x_1\alpha_1+\cdots+x_n\alpha_n.\]
例题 （反例）
  1. \({\mathscr A}\colon {\mathbb C}^3 \rightarrow {\mathbb C}^3\), \((x,y,z)\mapsto (x^2,xy,z^2)\) 不是\({\mathbb C}\)-线性的.
  2. \({\mathscr A}\colon {\mathbb C} \rightarrow {\mathbb C}\), \(z\mapsto \overline{z}\) 是\({\mathbb R}\)-线性的但不是\({\mathbb C}\)-线性的.

§7.1.3

线性映射 · 第3页

线性映射 / 线性映射

性质 （线性映射的基本性质）
设\({\mathscr A}\)为从\({\mathbb F}\)-线性空间\(V\)到\({\mathbb F}\)-线性空间\(W\)的线性映射. 则
  1. \({\mathscr A}(0)=0\);
  2. \({\mathscr A}(-\alpha) = -{\mathscr A}(\alpha)\), (\(\forall \alpha\in V\));
  3. 设\(\alpha_1,\cdots,\alpha_n\)为\(V\)的一组基. 若\(\alpha = \lambda_1\alpha_1 + \cdots + \lambda_n\alpha_n\),则
    \[{\mathscr A}(\alpha) = \lambda_1{\mathscr A}(\alpha_1) + \cdots + \lambda_n{\mathscr A}(\alpha_n).\]
    即,线性映射\({\mathscr A}\)由\({\mathscr A}(\alpha_1),\cdots,{\mathscr A}(\alpha_n)\)这\(n\)个向量唯一确定.
  4. 若\(\beta_1,\cdots,\beta_m\)线性相关,则\({\mathscr A}{\beta_1},\cdots,{\mathscr A}{\beta_m}\)也线性相关.
  5. 若\({\mathscr A}{\beta_1},\cdots,{\mathscr A}{\beta_m}\)线性无关,则\(\beta_1,\cdots,\beta_m\)也线性无关.
