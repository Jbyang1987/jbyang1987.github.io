§1.2.1

线性组合

向量 / 向量线性相关性

定义 （线性组合）
设 \(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\) 为一组向量, \(\lambda_1\), \(\lambda_2\), \(\cdots\), \(\lambda_m\) 为一组实数. 称向量
\[\lambda_1\vec{a}_1 + \lambda_2\vec{a}_2 + \cdots + \lambda_m\vec{a}_m\]
为向量 \(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\) 的线性组合.
也就是说,一组向量的线性组合就是从这组向量出发通过线性运算能够获得的向量.

§1.2.2

线性组合的几何意义

向量 / 向量线性相关性

  1. 设 \(\vec{a}\)为一个非零向量。则
    过原点与 \(\vec{a}\) 平行的直线 \(\overset{\quad 1:1 \quad}{\leftrightarrow}\) \(\vec{a}\)的全体线性组合.
  2. 设\(\vec{a},\vec{b}\)不平行(不共线). 则
    过原点与 \(\vec{a}\) 和 \(\vec{b}\) 平行的平面 \(\overset{\quad 1:1 \quad}{\leftrightarrow}\) \(\vec{a},\vec{b}\) 的全体线性组合.
这就是线性组合的威力:用少数几个向量表示特定子空间!

§1.2.3

线性相关与线性无关

向量 / 向量线性相关性

定义 （线性相关,线性无关）
给定一组向量 \(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\).
  • 如果存在一组不全为零的实数 \(\lambda_1\), \(\lambda_2\), \(\cdots\), \(\lambda_m\) 使得
    \[\lambda_1\vec{a}_1 + \lambda_2\vec{a}_2 + \cdots + \lambda_m\vec{a}_m=\vec{0},\]
    则称向量组\(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\)线性相关.
  • 反之,若对任意一组不全为零的实数\(\lambda_1\), \(\lambda_2\), \(\cdots\), \(\lambda_m\)都有
    \[\lambda_1\vec{a}_1 + \lambda_2\vec{a}_2 + \cdots + \lambda_m\vec{a}_m\neq \vec{0},\]
    则称向量组 \(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\)的线性无关.
特别地，设 \(\vec{a}_1\), \(\vec{a}_2\), \(\cdots\), \(\vec{a}_m\)线性无关. 若 \(\lambda_1\vec{a}_1 + \lambda_2\vec{a}_2 + \cdots + \lambda_m\vec{a}_m= \vec{0}\), 则 \(\lambda_1=\lambda_2= \cdots=\lambda_m=0\).
例题
证明向量组\(\vec{e}_1=\vec{a}+\vec{b}+\vec{c}\), \(\vec{e}_2=\vec{a}-\vec{b}-\vec{c}\), \(\vec{e}_3=\vec{a}+2\vec{b}+2\vec{c}\)线性相关。
\(3\vec{e}_1 - \vec{e}_2 - 2\vec{e}_3 =\vec{0}\) 或 \(\vec{e}_2 = 3\vec{e}_1-2\vec{e}_3\).

§1.2.4

线性相关性的几何判断

向量 / 向量线性相关性

  1. 一个向量\(\vec{a}\)线性相关 \(\iff\) \(\vec{a}=\vec0\);
  2. 两个向量\(\vec{a},\vec{b}\)线性相关 \(\iff\) \(\vec{a}\)与\(\vec{b}\)平行(共线);
  3. 三个向量\(\vec{a},\vec{b},\vec{c}\)线性相关 \(\iff\) \(\vec{a},\vec{b},\vec{c}\)共面;
  4. 四个及四个以上的向量一定线性相关.
