# 线性代数课程网站 · V0.1

这是一个可以长期维护的静态网站。所有页面都是普通文件，不需要账号、数据库、npm 或服务器端程序。分页网页已生成，直接打开或上传即可。把网站文件上传到个人主页，就可以供学生访问。

## 1. 文件放在哪里？

```text
线性代数课程网站/
├─ index.html                 首页
├─ chapters/
│  ├─ chapter01.html          第一章目录与整章阅读，旧锚点保留
│  └─ chapter01/section0X/    第一章各小节的知识页、目录及整节阅读
├─ content/chapter01/chapter01-section0X/  分页正文片段；1.1 手写维护，其余由整章内容生成
├─ scripts/build-lessons.js   根据目录和正文生成静态网页
├─ tests/progress.test.js     学习记录与旧版本迁移的测试
├─ css/
│  ├─ style.css               全站颜色、字号、间距和手机布局
│  ├─ chapter01.css           第一章的例题、表格等专用样式
```

首页文字在 `index.html`，第一章整章内容和旧锚点在 `chapters/chapter01.html`。1.1 的文字请修改 `content/chapter01/section01/` 中的片段；1.2–1.5 的分页片段保存在 `content/chapter01/chapter01-section0X/`，由生成脚本从整章页面按 `sourceRanges` 生成。不要直接修改生成的知识页或整章页面内的分页内容。不要手工修改 `assets/vendor` 里的工具文件。网站使用电脑自带字体，不请求在线字体。

## 2. 如何打开网站？

**快速看页面：** 双击 `index.html`，用 Edge、Chrome、Firefox 或 Safari 打开。公式工具已经放在本地，断网也可以排版。

**完整检查学习进度：** 请让 Codex“为这个网站启动本地预览，并打开首页”。它会提供类似 `http://127.0.0.1:8765/index.html` 的本机地址。这个预览仅向你自己电脑提供静态文件，不是网站所需的服务器端程序。网站上传个人主页以后，也不需要这个预览工具。

为什么有两种方法？双击文件会得到 `file://` 地址。不同浏览器对这种地址下的学习记录处理不一样，首页与章节之间可能无法共用记录。通过固定的本机地址预览，或上传后通过正式网址访问，才能可靠地共享学习进度。使用同一个浏览器和固定地址；更换端口也会被视为另一个网站。

**上传：** 将 `index.html`、`chapters`、`css`、`js`、`assets` 按原有层级一起上传。请保留文件夹名字。首页与章节使用相对路径，因此也能放在个人主页的某个子文件夹里。无需转换或打包。`README.md`、`讲稿`、`content`、`scripts` 和 `tests` 是维护资料，网站运行不需要上传它们。

## 3. 如何修改课程标题？

首页的主要标题位于 `index.html` 中的 `<h1 id="course-title">`。`<br>` 表示换行，可以保留或删除。副标题在 `class="hero-subtitle"` 的段落里。

浏览器标签页的名字在每页开头的 `<title>` 内。页眉与页脚也有课程名称；要整体改名，可以让 Codex：“把全站课程名称改为……，同步修改标题、页眉和页脚，但保留章节编号。”

## 4. 如何修改第一章某节的文字？

1.2–1.5：打开 `chapters/chapter01.html`，搜索小节标题，例如“复数与数域”。五节分别对应原稿的五个 `subsection`，每节被包在一个 `<section class="lesson" ...>` 中，并有中文注释标明编号。

- `<p>这里是文字</p>`：一个段落。
- `<h2>`：一节的标题；`<h3>`：思考、几何等教学环节的标题；`<h4>`：环节内的具体知识点。
- `<details>`：可以展开的自测答案；`<summary>`：学生点击的文字。
- `demo-placeholder`：未来互动演示的预留位置。目前只是明确标注的说明区域。
- `id="vector-operations"`：一节的固定地址。普通改文字时请保留它，否则目录和 上一节 / 下一节 的跳转需要一起修改。节内知识点也可有自己的地址，如 `vector-addition`。

每节按需要安排思考、几何、定义、例题、探索、即时自测等教学环节，按讲稿的教学逻辑组织，必要处增加性质和可展开的证明。可以在对应区域增加段落、公式或例子，不必改其他小节，也不必改 JavaScript。

### 第一章分页内容如何维护？

第一章五个小节都已拆成知识页：1.1 为 9 页，1.2 为 5 页，1.3 为 5 页，1.4 为 4 页，1.5 为 6 页。每个 `chapters/chapter01/section0X/` 目录中，`index.html` 是本节目录，`all.html` 是整节阅读及打印入口。

知识页使用层级编号：1.1 的页面依次为 1.1.1–1.1.9，其他小节按相同规则编号。点击“标记本页为已学会”后会自动进入下一页。

- **正文**：1.1 修改 `content/chapter01/section01/` 下对应的 HTML 片段；1.2–1.5 修改 `chapters/chapter01.html` 中对应的整节内容，再由生成器提取分页片段。图片路径会由生成器按页面深度修正。
- **标题、次序和说明**：修改 `js/course.js` 中第一章的 `lessons[0].pages`。`slug` 和学习记录编号已用于网址与存储，发布后应保持稳定。
- **生成**：在网站目录执行 `node scripts/build-lessons.js`。无需安装依赖。脚本会更新全部知识页、各节目录、整节阅读和原整章页面中的 1.1 入口。
- **检验**：执行 `node --test tests/progress.test.js tests/site.test.js`，再打开预览检查字号、公式和翻页。

正文始终保存在静态网页中，关闭脚本仍能阅读和翻页。手机目录默认折叠，电脑目录默认展开。整节页可使用浏览器打印；打印内容由相同正文生成。

每页都有独立“已学会”按钮；完成一个小节的全部知识页后，该小节才算完成。1.2–1.5 的整节阅读保留原有内容和锚点，分页页与整节页使用同一组生成片段。以后扩展其他章节时沿用同一层级与学习记录接口，并在 `js/course.js` 登记页面目录。

### 与讲稿的对应关系

课程顺序以 `讲稿/tex/线性代数 智慧课程.tex` 的章节列表为准，共 11 章；中文标题来自各章正文的 `section`。第 10、11 章保留讲稿中的 `*` 选学标记。绪论是开篇介绍，不另占一个章节编号。

第一章的实际内容来源是 `讲稿/tex/sections/01 vectors.tex`，外层“线性代数 01 第一章 向量.tex”只是载入它。五节对应如下：

| 讲稿中的一节 | 网页固定地址 |
| --- | --- |
| 向量及其运算 | `#vector-operations` |
| 向量线性相关性 | `#vector-dependence` |
| 坐标系、坐标与坐标变换 | `#coordinates` |
| 复数与数域 | `#complex-and-fields` |
| 数组向量 | `#array-vectors` |

原 TeX 文件没有修改。网页按五节改写，保留主要定义、八条性质、讲稿中的相关性例题、坐标变换公式、高维应用和基本向量，并补充过渡说明、自测与推导。原稿中注释掉的内容不作为新增教学单元。一般基与维数理论归于第六章，第一章只保留仿射坐标所需的三维基，以及数组的基本向量。

第一章讲稿中的 `Velocity.jpg`、`AB.png` 和 `Force.png` 已复制到 `assets/chapter01`，显示在“什么是向量”处；原文件仍在讲稿目录中。讲稿里的加法、减法、数乘、线性组合、仿射坐标系与复平面绘图，按原稿的数学关系重绘为 SVG，放回相应知识点。点与向量、点与坐标之间的一一对应、复数的代数表示，以及本章概念图也在对应位置。网页上的图片要连同整个 `assets` 文件夹上传，单独上传 HTML 会造成图片消失。

网页还做了几处准确性处理：数域的除法明确排除零除数；“四个向量必相关”限定于三维几何空间；区分数组分量数和受约束数据的自由度；DeepSeek-V3 例题按官方配置把乘式中的 `129208` 改为 `129280`，结果为 `926679040`。256、128、64 维图像特征合计 448 维，加入其他特征后才可能达到数千维。

以后修改 TeX **不会自动改变网页**。更新讲稿后，请让 Codex 重新对照相应章节同步内容。原来的 `chapter01` 学习记录编号保持不变，已有完成状态不会因本次内容改写而清除。

### 写数学公式

行内公式写成：

```html
<p>给定向量 \(\mathbf{v}=(1,2)\)，考虑它的长度。</p>
```

独立一行的公式写成：

```html
<div class="formula">
  \[a\mathbf{u}+b\mathbf{v}=\mathbf{w}.\]
</div>
```

矩阵也可以直接写 LaTeX，例如 `\begin{pmatrix}1 & 2 \\ 3 & 4\end{pmatrix}`。在 HTML 中写小于号时请用 `&lt;`，大于号可以写 `&gt;`。很长的公式在窄屏上可以在公式区域横向滚动，不会把整页撑宽。

当前公式工具采用固定版本的本地 MathJax SVG 组件，包含字形，支持常用基础与 AMS 数学命令。自动联网加载扩展和菜单已关闭。若以后需要特殊 LaTeX 扩展，让 Codex 把相应文件一起放到本地，并检查离线排版；不要只加在线链接。配置依据：[MathJax 组合组件说明](https://docs.mathjax.org/en/v3.2/web/components/combined.html)、[TeX 配置说明](https://docs.mathjax.org/en/v3.2/options/input/tex.html)。

### 加图片

把图片放到 `assets` 中，并写有意义的说明文字，例如：

```html
<img src="../assets/your-diagram.svg" alt="描述这张数学图所表达的关系">
```

以后加入互动演示时，建议把该章节独有的脚本放在 `js/chapter01-demo.js`，仅在第一章引入。不要把所有章节的演示混到 `main.js`。

## 5. 如何增加一个章节？

建议让 Codex 完成下面几步，你只需要提供章节主题和内容：

1. 复制 `chapters/chapter01.html` 为 `chapters/chapter02.html`。
2. 把新页面中 `data-chapter="chapter01"` 改成 `data-chapter="chapter02"`。这是学习记录使用的永久编号；**发布后不要随意改已有编号**。
3. 更新页面标题、介绍、目录、小节文字、每节的 `id`、目录链接、上一节 / 下一节 和页脚。共用 CSS 和通用脚本的路径不需要改变。第一章额外引入了 `css/chapter01.css`；若新章需要相同样式，可以将它复制成 `chapter02.css` 并修改新页的引用，使两章以后可分别维护。
4. 打开 `js/course.js`，找到 `chapter02`，将 `path: null` 改成 `path: "chapters/chapter02.html"`，并填入 `sections: 实际小节数`。保留逗号；可以照着第一章的格式写。
5. 首页课程地图会自动显示新章节，进度也会自动把它计入分母。同步更新首页底部“第一章已开放”的说明，以及新旧章节底部的“下一章”链接。
6. 检查新页面的公式、手机布局和完成按钮。

尚未准备好发布的章节，`path` 保持 `null`。它会显示“即将开放”，没有可点击的失效链接，也不参与进度计算。可以在 `course.js` 增加更多这样的条目。

## 6. 如何改变网站外观？

打开 `css/style.css`。最上面的 `:root` 是统一设置：

- `--font-body` / `--font-display`：正文字体 / 标题字体。
- `--text-...`：不同层级的字号。
- `--color-primary`：主色；`--color-muted`：次要文字颜色。
- `--color-background` / `--color-surface` / `--color-panel`：不同背景。
- `--width-page` / `--width-reading`：页面和阅读栏的最大宽度。
- `--space-...`：间距；`--radius`：圆角；`--border`：边框。

通常只改这些设置，就能统一改变风格。文件后半部分负责手机布局，不需要为手机再建一个网站。未来深色模式也可以通过覆盖同一组颜色变量实现。

当前默认正文为 22 像素，辅助文字为 18–20 像素，公式随所在正文一起放大。字号使用相对单位，也会响应浏览器的字体设置。窄屏上的宽公式、表格和示意图可在各自区域横向滚动，避免缩小文字。页面界面统一使用中文；讲稿原有的英文名称、缩写和数学符号保留。

## 7. 学习记录保存在哪里？

阅读知识页会自动记录上次读到哪一页；翻页不会自动标为学会。点击 **标记本页为已学会** 才会更新完成状态，可随时撤销。首页“继续学习”回到上次阅读位置，没有阅读记录时从第一个未完成内容开始。

1.1–1.5 分别按 9、5、5、4、6 个知识页计数，当前第一章共 29 项。完成某小节的全部知识页才完成该小节，完成全部 29 项才完成第一章。整章页底部仍保留批量标记按钮。

数据保存在当前浏览器的 **localStorage** 中，名称为 `linear-algebra.learning.v2`，包含版本、章节与知识页的完成状态、完成时间，以及最近阅读页的编号和时间。旧的 `linear-algebra.learning.v1` 整章完成记录会迁移为各页完成状态，旧键保留；新记录存在时优先读取新记录。同一网站下不同标签页的进度会同步刷新。

记录不上传，不跨浏览器或电脑同步。清除网站数据后记录会消失；隐私浏览关闭后也可能清除。浏览器禁止存储或空间不足时，标记仍可在当前页面使用，但页面会提示无法保存。遇到无法读取的旧记录时，不会自动覆盖它。

所有存储读写都在 `js/progress.js`。以后修改记录格式应继续保留迁移机制；知识页和章节编号不要随意改动。

## 8. 以后怎样让 Codex 帮你修改？

先打开这个文件夹，再用自然语言说清楚“位置、目标、需要保留什么”。例如：

> 根据讲稿修改第一章 1.2“向量线性相关性”：增加一个三维空间中两个向量的线性组合构成平面的例子。沿用现有教学环节，不修改其他小节。

> 在第一章的“探索”环节中增加一个可以拖动的二维向量演示，支持手机触摸和键盘。继续使用普通 JavaScript，不引入框架。

> 按第一章的布局新增第二章“线性方程组”。先只建立结构和三个示例小节，更新课程地图和前后导航。

> 把全站正文调大一点，适合 iPad 阅读。请检查手机布局与长公式，不改变教学内容。

建议在每次修改前复制整个文件夹，存成一个日期命名的备份，例如“线性代数网站-2026-09-24”。不满意时就能恢复。
